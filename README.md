# Independent Bookstore Events Page

This is a digital events management desk built for bookstore floor staff (Ticket: ENG-18072). It allows staff to easily view, search, add, edit, and manage upcoming bookstore events instead of using paper sheets or Excel files.

## Live Website
[Open Live Website](https://independent-bookstore-events.vercel.app)


## Technologies Used
- HTML5 (Semantic structure)
- CSS3 (Vanilla CSS, Responsive Grid and Flexbox)
- Vanilla JavaScript (DOM manipulation and localStorage)

## Main Features
- View upcoming bookstore events with date, time, and capacity.
- Real-time search by title, category, location, or keyword.
- Add new events and edit existing events.
- Custom category option ("Other") with dynamic text field.
- Delete confirmation modal dialog to prevent accidental deletion.
- Empty state message ("No data found") when search has no results.
- Visual loading spinner during simulated network operations.
- Form validation highlighting invalid fields with red borders.
- LocalStorage support so data stays saved on refresh.

## Project Files
- `index.html` - page structure and forms
- `styles.css` - layout, colors, and responsive design
- `script.js` - event logic, validation, and search
- `README.md` - project overview and documentation

## How to Run
Open `index.html` in any web browser, or run with VS Code Live Server.
